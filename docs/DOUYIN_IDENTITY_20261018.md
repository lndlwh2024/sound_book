## 行为

- 点击“读取平台昵称”时，先读本人区域；必要时悬停当前头像，等待账号菜单，再读取本人昵称。支持头像内部菜单、ARIA关联的弹出层，以及位置相邻且包含本人账号操作的菜单。
- 不点击上传、退出登录、切换账号等操作；不将其他作品作者、本地缓存昵称、页面标题或图片alt文字作为本人昵称。多个候选不自动覆盖。
- 自动轮询只读当前页面，不反复移动鼠标；只有明确读取请求、旧登录成功后读取及需要核对已绑定昵称的部署前检查才展开本人菜单。
- 未读到昵称时保留已有昵称、稳定账号ID、浏览器目录、登录状态和发布账本。发布入口/头像仍可见时明确提示无需重新扫码；只有页面显示登录要求时提示完成登录。
- 昵称读取失败自动保存当前DOM与截图，可点击“打开采集报告”查看；诊断补充账号区域节点及弹出层ARIA关系。
- 部署前检查同步支持隐藏昵称；实际昵称与所绑定昵称不一致仍拒绝上传，不自行改绑。

## 使用

关闭当前登录/采集会话并重启新版书声，选择原账号，点击“登录 / 获取平台昵称”，然后点击“读取平台昵称”。现有浏览器登录目录会继续使用，无需退出账号或清理Cookie。读取成功后下拉框显示平台真实昵称，历史成功记录、额度和目录绑定仍属于原稳定账号ID。

本次没有直接修改用户账号名称、登录凭据或发布账本；实际昵称需要在新版运行时从已登录页面读取。若当前平台菜单仍未能识别，新版会留下展开后的DOM与截图，方便继续定位，而不是要求反复登录。
