# 完整版与部署版统一维护（2026.10.19.3）

## 改动前基线

用户要求先保存当前版本再改动。基线提交为 `68511601201edcf255c010599daca83a6c65d487`，改动前已经推送至origin/main，并通过远端引用核对。基线包含此前完整验证过的发布修复、独立部署入口、失败证据、托盘及相关测试；账号、授权、浏览器目录、模型和发行ZIP不提交。

本轮围绕窗口组织、工作区提取和统一版本号进行改动。制作和发布业务算法不重写。

## 界面与代码关系

- Sheet1：现有有声视频生产工坊。
- Sheet2：现有多平台自动发布，继续创建原来的MultiPlatformPublisherPanel。
- Sheet3：名称为“多平台自动发布独立部署版”，呈灰色禁用。点击标签提示“只有独立的部署版才可使用”，保持当前页面。该入口只创建LockedPublisherSheet，不创建账号仓库、监听器、浏览器或上传任务。
- 独立部署入口：PublisherWindow作为窗口与托盘宿主，直接加载PublisherWorkspace。该工作区包含原独立部署版的界面、账号控制和运行设置，沿用1366×768设计，不另做Win11布局分支。

PublisherPanel继续继承Sheet2使用的MultiPlatformPublisherPanel。因此两种工作区调用同一套云盘同步、补扫、下载去重、发布、草稿恢复、结果校验、重试、归档和诊断实现。修复这些共同功能时修改其共用模块即可，不复制业务代码到第二份目录。

## 统一版本与环境配置

产品版本、发布组件版本、窗口和发行清单统一从src/version.py读取。src/__init__.py与src/publisher/__init__.py仅导出该版本，不分别保存版本常量。

src/edition.py声明两个宿主的能力：完整版不开放独立部署工作区、Windows自启、启动恢复或部署媒体预算；独立部署入口保留这些能力及原运行设置。完整版Sheet2仍按原有行为工作，不接入独立部署的后台恢复机制或预算。

两版使用同一个仓库及发布提交。构建部署包时直接使用独立工作区及其依赖，不包含制作窗口、语音、视频生产模块或模型；无需为部署版长期维护分叉业务代码。浏览器及依赖锁可随目标环境不同，版本号仍统一。

本轮没有把托盘加入完整版；被撤回的方案内容不在此次范围。独立部署版保留原托盘和安全退出行为。
