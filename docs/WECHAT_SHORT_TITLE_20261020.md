# 微信视频号短标题自动缩写 · 2026.10.20.2

微信视频号的短标题在填写前固定限制为 **16 个字符以内，包含标点和省略号**。这一逻辑仅位于微信视频号上传器中，完整版和独立部署版共用；不新增账号配置项，不改变其他平台标题。

不足或等于 16 字时保留原题。超长时按本地规则精简问句和冗余表达，保留主体、否定词和数值关系；例如：

> 为什么水珠在荷叶上滚来滚去，就是沾不湿它？
>
> → 为何水珠在荷叶上滚动，沾不湿它？（16 字，含标点）

规则缩写后仍然超长的标题，保留首尾要点并用“…”标明中间删节。这是确定性的本地缩写和省略，不依赖 AI 接口、网络或额外凭据，也不保证任意长标题都能完整保留语义。

系列名称、文件名、自定义三种非空标题来源都在微信视频号填写时经过此处理；“空”仍保持为空。文件名来源可去掉书声生成的日期与版本尾缀。原文件、原标题配置和其他平台解析结果保持原值。

长度按浏览器 UTF-16 计数，标点、空格均计入，emoji 按浏览器实际长度保守计算；截取不会切断代理对。即使网页没有 `maxlength` 或给出大于 16 的属性，内部仍强制上限；若网页要求更短，则服从更短限制。

日志记录原题、实际短标题及两者长度。填写后回读确认，实际短标题进入发布结果和成功回执。原来的身份核对、上传、合集、不显示位置、发布成功确认、重试限制与 `publiced` 归档流程沿用现有实现。

验证包含现场长标题、16 字边界、标点、数字、emoji、无 `maxlength` 的页面、多种标题来源及本地模拟的完整提交。没有向真实账号发表视频。
