# 2026.10.29.2 双版本完整交付

部署版使用现有独立 EXE 构建链。完整版保留生产工坊和多平台发布，采用附带 Python 的便携发行目录，避免把多环境语音工作进程错误冻结进单个主程序。

完整版包含主程序环境、F5/Kokoro 工作环境、CPython 3.12.11、FFmpeg/FFprobe、匹配主环境 Playwright 的 Chromium，以及本机已安装的核心 F5、Kokoro、Qwen、SD1.5、LCM 和 Vocos 公开模型缓存。相同权重在压缩包中只存一份；启动时在包内生成模型路径别名，优先使用硬链接，不支持时复制。需要完整解压后启动，目录必须可写。

运行 `ShuShengFull.exe` 或 `启动书声完整版.bat`。首次启动会根据解压位置重建包内 Python 环境路径，不修改系统 Python、系统代理或用户已有浏览器账号。发布账号和授权沿用程序已有的用户数据策略，包内不附带开发机账号、凭据、书稿、输出文件或 `.env`。Azure 等在线服务仍需用户配置授权；GPU 加速仍需目标电脑兼容的显卡及驱动。

完整版构建：`tools/build_full.py` 显式接收 Python 基础运行时、公开模型缓存、浏览器缓存和 FFmpeg 发行目录；先复制，再运行 `tools/full_launcher.py --self-check --output <报告>` 验证，最后使用 `--archive-only` 生成 ZIP64 包。运行时自检只使用临时账号配置和离线浏览器页面，不发布视频、不操作真实频道。

完整版与部署版共用 `src/version.py` 和发布代码。交付校验包含各自的来源提交、源文件 SHA256、压缩包 SHA256 及独立自检结果。真实平台登录持续性和 VPN 切换后的实际网络表现仍以用户后续运行观察为准，不用离线自检替代。
