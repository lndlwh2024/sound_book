# 上传间隔与YouTube配置位置修复

统一版本：2026.10.20.6。完整版与独立部署版共用发布调度代码；仅部署版的小屏布局需要移动YouTube控件，完整版本已有标题来源配置保持原位置和行为。

## 时间设置

| 设置 | 当前行为 |
| --- | --- |
| 网盘刷新 | 使用各账号界面保存的值，例如600秒；不覆盖现有配置、不新增设置项。 |
| 两次上传之间 | 上一个上传任务及浏览器收尾完成后，单独空闲等待5秒，再处理下一次可执行上传。代码固定，无界面配置。 |
| 暂时没有本地新视频 | 默认每5秒检查本地；下载完成通知可立即唤醒检查，不额外访问网盘。 |

原来的上传后30秒等待和处理完当前文件后300秒等待均已替换。不在最后一次手工上传结束后再做无意义等待。

5秒只计算空闲等待。当前保留的“提交后浏览器继续等待5秒收取回执”属于当前上传的收尾，完整保留且不抵扣下一次上传前的5秒。因此，如果浏览器收尾用了5秒，之后仍另外等待5秒。

有下载通知时可马上检查本地文件，但不能跳过两次上传之间的5秒空闲等待。浏览器仍串行执行；一个上传及收尾完成后才会开始下一个。停止、暂停可打断等待。

只有已经下载完整、校验通过且符合原有发布条件的文件才上传。成功不重传，失败2跨重启保留、需手工重试；额度、登录、人工核验、每个文件的平台执行顺序及publiced归档规则不变。手工任务完成后仍停止，不自动变为持续监听。

网盘请求、下载和网络错误重试继续由现有云盘模块处理。本地每5秒检查不触发每5秒刷新Google Drive；云盘接入关闭或网络不可用时，已下载的本地文件仍可发布。上传和平台确认的超时逻辑不变，制作管线不变。

## YouTube界面

独立部署版“部署配置 → 发布信息”集中显示频道ID、播放列表、公开范围、是否面向儿童、AI内容声明、缩略图、标题来源与说明。标题来源继续提供“空、系列名称、文件名、自定义”；选择自定义后，输入框在同一行展开。

“发布规则”只保留媒体类型、每日上传上限及归档设置，与其他平台按相同用途组织。控件直接移动，不新建第二份标题配置，也不改变账号保存格式和发布时的标题解析。

按1366×768屏幕扣除窗口栏及任务栏后的可用高度检查，不使用配置表单滚动条，保存及部署按钮独立可见。
