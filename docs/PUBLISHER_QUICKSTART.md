1. 解压整个文件夹至固定位置，保留 `_internal` 与 exe 的相对位置，不要只复制 exe。不需要安装Python、Node、Git或Chrome。保留系统Edge用于Google网页授权。
2. 双击 `自检.cmd`，生成不含凭据的 `self-check.json`，检查Qt、私有浏览器、真实H.264/AAC视频解码、FFprobe、目录权限和空间。Windows缺少运行库时使用微软官方VC++ x64运行库安装程序；不要下载单个DLL。
3. 双击 `ShuShengPublisher.exe`。用户数据默认在 `%LOCALAPPDATA%\ShuShengPublisher`，独立于完整版；媒体目录在界面选择。
4. 通过公共云盘绑定导入本地Google桌面OAuth配置并重新授权。新电脑不复制旧令牌、Cookie或浏览器profile。各平台重新登录、核验账号，保存目录、媒体类型和额度。无需重新采集所有平台DOM，内置平台适配随包提供；页面改版、识别异常时才补采对应页面用于诊断。
5. 先选择用户指定的测试内容验证登录、下载、上传和平台确认。确认完整流程后，可在“运行设置”启用登录自启和恢复部署。云盘监听直接按公共接入开关及各账号保存的监听配置运行。登录任务延迟90秒，以当前用户普通权限运行；不配置Windows自动登录，不修改电源设置。

YouTube首次登录若提示“此浏览器或应用可能不安全”，在该账号的“登录 / 获取平台昵称”窗口点击“手工登录 Google（正常 Chrome / Edge）”。本人在专用浏览器中登录、进入正确频道后，回到书声点击底部始终可用的 **“核验登录与上传入口”**；书声正常关闭该专用窗口，等待目录释放后自动核验频道ID和昵称并保存。手工期间采集与昵称读取暂停，禁用按钮呈灰色。不要用“取消等待并关闭”代替完成验证；取消会保留浏览器及登录数据，下次打开可继续。若上一版已经登录，不需删除账号或重登，先更新后进入原账号登录窗口继续验证。普通浏览器仍被拒绝时按Google提示处理，无需重采全部DOM。[交接修复说明](YOUTUBE_LOGIN_HANDOFF_20261019.md)。

## 两台电脑的分工

抖音已登录时可直接点击“读取平台昵称”：新版优先读取头像账号菜单，必要时在临时标签页检查首页本人账号卡，保留当前上传页；读不到昵称会保留原绑定、保存DOM与截图，不要求反复扫码。[昵称修复说明](DOUYIN_IDENTITY_20261018.md)。

未成功任务的最后截图、DOM、完整任务日志及结果清单保存在 `%LOCALAPPDATA%\ShuShengPublisher\multi_platform\failure_diagnostics\平台名\日期\`，文件名带任务ID和北京时间。成功任务仅保留正常日志。未启动浏览器或页面已关闭时会明确记录无法采集截图的原因。详见[失败证据与YouTube核验修复](YOUTUBE_FAILURE_DIAGNOSTICS_20261018.md)。监视队列隐藏本次未选平台列，归档规则保持。

原机完整版可继续制作并同步云盘，X230发布版下载和发布。相同Google Drive可由不同电脑读取；同一平台同一发布账号只交给一台电脑自动部署。当前账本在本地，不提供跨电脑锁或跨机去重。

## 自动运行与暂停

第一次启动不会自动投稿。已有云盘连接和有效监听绑定时，启动程序即独立轮询、下载，与当前发布平台勾选及发布账号选择无关。手动启动部署后保存本次选定的稳定账号ID；下次恢复发布只使用这些账号，不自动加入新增账号。主动“停止部署”或“暂停全部平台”会持久保存部署运行意图，云盘继续工作。停止下载请关闭公共“启用云盘接入”、关闭相应账号监听或断开云盘。本版点击主窗口关闭按钮会真正退出；后台运行请显式选择托盘“最小化到托盘”。退出先停止工作并关闭自有浏览器，超时执行有界回收，释放旧目录及单实例锁；下次启动时仍按保存的云盘开关和监听绑定生效。

启动时继续执行当前登录、身份和页面访问检查；内置页面结构不能用作登录成功的依据。网络失败递增等待，授权失效等待人工重新连接。配置缺失显示原因。云盘网络不可用时，已经下载的本地文件仍可发布。中断上传或提交且未确认成功的记录需要在“运行设置→核验中断投稿”核对平台作品列表，确认已发布后记成功，确认未发布后才允许再次上传。

同一云盘根目录下若存在多个相同日期的文件夹，会遍历全部已有目录并按文件ID合并，不创建或删除云端目录。发布继续按账号及内容SHA-256去重。

同一本地目录、同一Google账号和同一云盘路径下，同一云端文件仅变更版本号或修改时间时，会核对已有文件的大小、MD5及记录的SHA-256后复用，不因版本信息变化另存副本；实际内容变化、云端文件ID或绑定范围不同仍独立处理。不接管未登记的用户文件。旧版本已经产生的副本需要停机后校验整理，新版不会在上传过程中自动移动它们。

同账号、同内容累计最多两次自动尝试，“失败2”在定时扫描和重启后保留，不再反复打开核对浏览器。修复原因后，在队列中选择文件并点击“手动上传所选媒体”，选择目标账号，确认后才为相应失败项开启新一轮重试；已成功项不重传。YouTube优先继续已保存视频ID的草稿，不重新选择文件。已有旧重复草稿保留，核验后由用户决定如何整理。

“手动上传所选媒体”是限定所选文件的一次任务：已成功平台连同上传预检一起跳过，未完成平台继续处理；全部完成后部署自动停止。本轮存在失败也会明确提示本轮结束及结果，不伪称全部成功。单次手工任务不保存为持续部署的自动恢复意图；已全部完成的文件不会因再次手工上传而重复发稿。常规“启动部署”仍按原有目录轮询运行。

日志下方有“全部、公共/云盘、抖音、快手、微信视频号、YouTube”标签。云盘扫描、下载和状态只进入“全部”和“公共/云盘”，平台标签只显示平台发布记录，旧版云盘日志回放也按此分流；阅读历史时保留滚动位置。每条包含北京时间、账号、文件、阶段和结果。底部“导出诊断包”仅包含最新任务：运行中导出当前任务的快照，否则导出最近启动的任务；预检失败也计为一次任务。同一平台、账号、文件、失败阶段仅保留最后两次截图与DOM；完整任务日志只放一份，附任务摘要、结果及缺失项清单，缺失时不会拿旧任务补齐。异常显示为红色，明确成功为绿色。本地历史与正常日志轮转仍保留，导出范围不随界面显示的历史日志扩大。

右侧监视队列正在处理的文件整行使用柔和绿色文字，选中时仍保持绿色；处理结束、失败或任务退出后恢复原色。颜色表示当前操作状态，不表示发布成功。

默认媒体、临时文件与归档合计预算30GB，并在新下载前保留10GB磁盘空间；空间不足暂停新下载，不自动删文件。本地发布不受该下载保护阻塞。日志轮换上限约100MB，账本与日期断点不随日志清理。

## 更新、备份与回滚

先停止部署、等待在途任务结束并退出。备份整个用户数据目录和需要保留的媒体；SQLite数据库必须在退出后备份。程序更新解压至新目录，保留原数据目录，不用空白配置覆盖它。启动新版并在运行设置重新保存登录自启，更新exe路径。回滚也保留新数据，不用旧备份覆盖新成功记录；遇到格式不兼容先停止。

跨电脑历史迁移须保留账号ID、成功账本、额度及日期游标，并映射新媒体路径；直接复制旧下载数据库可能留下指向H盘的记录。发行包提供以下离线迁移入口，只允许导入全新目录，不覆盖已有数据。先停止并退出原机相同账号的部署，再在原机执行（把exe路径替换为实际解压位置）：

```powershell
& 'D:\ShuShengPublisher\ShuShengPublisher.exe' --export-history 'D:\书声历史.zip' --source-data 'H:\业务\soundbook\data' --source-stopped
```

把历史zip复制到新机。按原账号JSON中的稳定 `account_id` 编写路径映射，例如 `{"youtube:原账号ID":"D:/书声媒体/趣味知识","douyin:原账号ID":"D:/书声媒体/趣味知识"}`；共用同一云盘同一目录的账号映射到同一个本地目录，目录需先创建。新机在首次打开GUI之前执行：

```powershell
& 'D:\ShuShengPublisher\ShuShengPublisher.exe' --import-history 'D:\书声历史.zip' --path-map 'D:\目录映射.json' --source-stopped
```

默认导入 `%LOCALAPPDATA%\ShuShengPublisher`，该目录必须尚不存在；如已初始化，改用 `--data-dir D:\书声发布数据` 指定全新目录，日后启动及自启均使用此目录。导出不含Google凭据、浏览器profile、Cookie或媒体；导入会清除旧登录状态，关闭自动恢复，保留账号ID、业务参数、成功账本、额度和日期断点。缺少本地媒体且尚未成功的旧下载记录会重新排队。媒体可另行复制，存在时会校验摘要。

不要混合两台机器的数据库或同时启用同一账号。若只做全新初始化而不迁移历史，旧内容可能被视为新任务，应从新日期/专用云盘目录开始测试。

关闭登录自启在“运行设置”取消对应选项并保存，仅移除当前用户的 `ShuShengPublisher-用户标识` 任务。需要用户保持登录，通电不睡眠由用户按需配置；锁屏、睡眠恢复、断网恢复和真实投稿仍以目标机验收结果为准。

## 构建版本说明

候选组合为Python 3.12.11 x64、PySide6 6.8.3、Playwright 1.56.0及其配套Chromium 141.0.7390.37、FFprobe 7.1.1。依赖均独立于完整版，运行时固定版本见 `requirements-publisher-lock.txt`，完整文件校验见 `manifest.json`。

此组合用于Win10适配验证，不能视为持续获得当前浏览器安全更新的正式发布组合。当前Playwright官方支持范围已是Win11及以上；本候选在Win10和X230通过启动与发布验收、并明确浏览器维护/升级策略前，不作为正式长期无人值守版本交付。Qt 6.8的官方平台表包含Windows10 1809及以后版本：[Qt平台表](https://doc.qt.io/qt-6.8/supported-platforms.html)；配套Chromium版本可核对[Playwright 1.56源码](https://github.com/microsoft/playwright-python/tree/v1.56.0)，当前支持范围见[Playwright系统要求](https://playwright.dev/python/docs/intro#system-requirements)。
