# 2026.10.26.1：账号隔离、连续批量上传和退出回收

本版执行2026-10-26确认的方案。源码、独立部署EXE、ZIP和说明使用同一个提交；交付核对和实际测试记录另附。YouTube仍使用既有上传、处理、检查及向导顺序，不提前关窗、不跳过步骤。

## 可观察行为

- 账号状态依据实际入口检查或上传结果更新。需要登录显示红色及原因，网络或浏览器异常显示检查失败；历史授权、读取昵称和人工确认不能代替实时检查。下拉框、登录状态和运行原因按稳定账号ID同步，不改变其他账号或文件结果。
- 预检逐账号进行。失败账号暂停，其余通过的账号启动；失败账号仍在本任务必需目标内，所以其他账号成功不会使文件提前归档。全部账号暂停时连续任务等待处理，用户仍可停止任务；手工批次结束时保留失败文件。
- 本轮文件清单固定，按平台、账号依次完成该账号的全部文件，再切换下一个账号；账号浏览器在本批次内复用。每文件仍使用独立上传器、请求监听和结果；新下载文件进入下一轮，成功项不重传，额度和重试上限保留。
- 自动上传不再悬停抖音头像。昵称变化可同步，同步失败继续上传；用户显式“读取昵称”与自动上传路径分开。
- 公共轮询时间旁新增“立即轮询”，针对全部已保存有效绑定；不自动保存其他未保存表单。正在扫描时最多合并一次后续全量请求，不并行下载。
- 已登记的云盘内容手工移到同目录`publiced`后，若必需目标未全完成则记录为人工暂停。原路径不存在也保留队列行，未完成目标显示人工暂停，既有成功目标仍显示成功；不把手移当发布成功，也不自动重新下载同作用域、同内容。使用队列旁“恢复人工暂停”明确恢复，校验当前云盘账号、目录与内容，保留原发布结果和次数。
- 最新诊断导出增加最近一次独立云盘扫描编号及有关原始日志、当次登录快照差异摘要。仍不导出其他发布任务历史、凭据、浏览器profile或指纹密钥。

## 登录快照和空闲验收

真实入口核验或发布成功后更新同账号快照，保留最近成功与前一份。内容为登录相关文件的大小、时间、有限量HMAC指纹以及可取得的Cookie数量/脱敏指纹，不复制明文Cookie或会话值。失败先采集再关闭页面，与最近成功基线比较，摘要写到窗口、日志和当次诊断；失败不会覆盖成功基线。

浏览器运行中和正常关闭后分别建基线。变动中的数据库、文件占用、数量/体积截断都会记录为限制；令牌刷新或文件变化本身不能被认定为登录丢失原因，不自动恢复旧会话。

“运行设置 → 登录空闲验收（不上传内容）”可选择账号及独立的4或8小时用例。开始时真实检查一次、关闭浏览器、自动等待，再检查一次并生成报告。不选择视频、不创建草稿、不保存或发布；账号在观察期参加正常任务则验收作废，不延迟生产。窗口可关闭后继续，取消会等待当前只读检查返回，退出书声会结束测试。

命令行同样支持：`ShuShengPublisher.exe --data-dir <数据目录> --idle-login-check <平台:稳定账号ID> --idle-hours 4 --output <报告路径>`。这是显式测试工具，不随部署自动启动。工具测试通过不等于已经完成真实4/8小时或真实视频上传验收。

## 退出

右上角关闭和托盘“退出”进入真正退出；需要后台运行时使用托盘的“最小化到托盘”。先保留所选恢复意图、停止新增工作、轮询及在途工作、关闭专用浏览器/驱动并记录阻塞项。正常结束不再等待无限循环；超时由系统辅助程序仅回收经过PID、创建时间、可执行路径及专用profile核验的书声自有进程，最后结束主进程，单实例锁随真实owner退出释放。

辅助程序和日志位于用户数据目录，不从旧发布目录加载代码，避免辅助程序自身锁住待删除的旧包。不会按名称结束所有Chrome、Edge或Python，不删除媒体、发布记录、授权或浏览器账号目录。退出日志用于继续定位具体阻塞项。

## 仍不作已解决承诺

- 真实平台会话丢失的最终原因尚未闭环；本版增加稳定观察、减少浏览器切换、准确状态及快照，不能承诺平台账号永不过期。
- 香蕉视频在ID、内容不变时跨日再次下载的现场原因仍待对应证据。新增人工隔离和日志用于保护与定位，不把它冒充该次问题的已证实根因修复。
- Win10 X230实机完整验收、真实4/8小时空闲测试和真实账号视频发布，只能以实际执行记录为准，不能用本地模拟测试代替。
