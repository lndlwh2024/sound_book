# 云盘独立轮询与下载（2026.10.25.2）

云盘监听不再依赖任何部署状态。

- 启动程序时，公共接入已开启、云盘连接有效、账号已启用且监听已开启并保存目录，即开始检查和下载。
- 按所有有效账号的监听绑定工作，不使用部署平台勾选、上次部署账号列表或本次手工上传范围筛选。
- 部署未启动、预检失败、等待登录、暂停、停止、单文件手工上传及手工任务结束均不停止云盘轮询与下载。
- 下载使用公共轮询间隔；跨日立即检查新日期，关闭后重新开启接入或重新连接会立即检查。相同云端版本去重及全部必需平台完成后归档的规则保持。
- 关闭公共接入、关闭对应账号监听、关闭账号、断开云盘或退出程序时停止相应下载。授权失效和存储不足仍明确报告并保留待处理文件。
- “运行设置”移除“下次启动自动恢复云盘监听”；旧状态文件的 `auto_watch` 仅保留兼容读取，不再控制下载。发布自动恢复仍由独立选项及部署意图控制。
- 运行设置和托盘的停止操作改为“停止部署（云盘监听继续）”；托盘分别显示部署与云盘状态。
- 云盘日志保持在公共/云盘标签，不归入发布平台或借用发布任务编号。最新诊断仍附当前云盘最近扫描状态；从未运行发布任务时也可导出当前云盘快照，不混入历史任务日志。

本版保留25.1对浏览器会话、原标签恢复、启动等待和准确失败信息的修复，没有新增代理分流或更改平台发布规则。会话保留已在本地Chrome141连续重开测试中验证，X230平台端的实际登录保持仍需实机确认。

验证使用临时配置、真实下载线程和模拟Drive，证明在没有启动部署且账号未登录时，多个绑定目录会收到经校验文件；发布暂停和停止时继续按真实轮询间隔下载新文件，公共开关可停止和恢复下载。

13组针对性测试共201项通过，包括五个平台连续重开会话、未部署自动下载、发布暂停/停止继续下载、去重、跨日、归档、诊断导出和界面控制。结果记录：`output/publisher-independent-cloud-tests.json`。
