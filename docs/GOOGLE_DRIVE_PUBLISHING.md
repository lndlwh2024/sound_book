# Google云盘资源绑定与自动发布（2026-10-16）

本文件记录用户确认的DEMO及其正式Qt实现。历史各节保留当时的实现与验证记录；最新行为以文末更新为准。覆盖资源绑定、只读授权、日期断点轮询、下载去重和账号配置布局；不更改视频生产、TTS、GPU温控或平台网页发布步骤。

## 1. 首次连接与使用

1. 在Google Cloud项目启用Google Drive API，创建 **桌面应用** 类型OAuth客户端并下载JSON。客户端属于书声应用，不是某个发布平台账号，也不是收费模型的API key。
2. 在书声“资源绑定”点击“连接”，首次通过文件选择器导入该JSON。系统浏览器会打开Google登录/同意页面。书声先启动127.0.0.1随机端口监听，再打开浏览器，避免回调端口不存在。
3. 授权成功后显示“已连接”；取消或超时维持此前连接。刷新令牌使用当前Windows用户的DPAPI加密保存，不写入账号JSON或日志。
4. 为每个平台+账号勾选“启用云盘监听”，通过目录选择器绑定系列目录，例如“书声 / 趣味知识”。可以逐层双击选择，也可以打开有权限访问的共享文件夹链接/ID。绑定的是系列目录，不是日期目录。
5. 绑定一个已存在、可写的本地目录，勾选媒体类型，设置账号每日上限、归档及平台参数，点击独立的“保存当前账号配置”。不同账号可绑定相同或不同系列目录及本地目录，多组绑定可同时工作。
6. 选择发布平台并“启动部署”，确认本次账号后沿用扫描清理、登录/DOM/身份预检；通过后开启本次任务的云盘监听和本地发布。下载完成立即唤醒发布线程。
7. “立即检查”会保存当前表单，并单次检查/下载；空闲时不会绕过“启动部署”和平台预检擅自投稿。暂停全部平台时暂停周期云盘下载，当前下载通过检查点取消；明确点击“立即检查”仍可单次取文件。

“断开”是整组生产云盘连接的本机断开：停止云端检查及下载、删除本机令牌，保留所有账号的绑定、下载版本记录、历史成功记录和本地文件。已下载的文件仍可按原本地发布流程处理。断开不删除云端数据，也不撤销Google网页上其他应用的授权。需要全局撤销时由用户在Google账号安全页操作。重新连接或更换Google账号后请重新确认目录权限。

## 2. 权限与配置

- 使用官方OAuth桌面回环流程、随机state、PKCE S256、离线授权，浏览器中的登录/同意由用户完成。
- 权限为`https://www.googleapis.com/auth/drive.readonly`。这个权限允许读取该Google账号可访问的Drive内容，并非Google提供的“仅一个文件夹授权”；书声自身只遍历配置的系列目录及当日子目录。界面授权说明明确告知权限范围。
- 只实现files.get、files.list和媒体下载。没有云盘上传、移动、改名、删除或创建目录的API方法。
- OAuth端点固定为Google官方地址；导入JSON不允许覆盖端点。回调不记录授权码，HTTP重定向不携带令牌自动跨域转发。网络连接/读取有20秒超时；取消和关闭不强行终止写文件线程。
- 客户端文件在`data/multi_platform/google_drive/client.json`；加密授权在同目录`credentials.dpapi`。均处于Git忽略的data目录。不要将客户端JSON、令牌或实际用户文件加入版本库。
- 原账号ID、浏览器profile、登录、DOM和每日额度记录不迁移、不重建。旧配置缺少drive_binding时等价于未启用。

## 3. 当日目录、文件版本与下载

- 使用北京时间`YYYY-MM-DD`作为当日子目录名，例如`2026-10-16`。每轮重新计算日期；不存在则等待后续轮询，不报配置损坏。同名日期目录存在多份时报错并等待用户整理，避免选错。
- 默认轮询15秒，可设5至86400秒。按日期断点逐日补扫至当天，只遍历各日期文件夹的直接子文件，按已有媒体类型扩展名筛选；不递归其他子目录、不跟随快捷方式、不导出Google文档。没有稳定大小/MD5的文件等待后续轮询。
- 版本键为“平台+账号、本地目录+系列目录ID、Drive文件ID、version/modifiedTime/size/MD5”。同版本完成下载后持久跳过，归档、重启、改账号显示名称不会触发重新下载。改变本地绑定目录会形成新的接收范围。
- 新云端副本拥有新的文件ID，即使名称/内容相同，也会先下载到该账号绑定的本地目录，再用SHA-256核对该平台账号历史成功记录。文件名不作为成功依据，A账号成功不代表B账号成功。
- 下载写入隐藏`.part`文件，并保存预定最终路径；完成后验证大小、MD5、SHA-256，回读云端版本，确认下载期间未变化后才移入媒体队列。待提交标记让原上传器和扫描清理跳过未提交文件。
- 重名不会覆盖本地文件，使用稳定短后缀区分。下载中断删除临时片段，下轮从头重试；若已完成重命名但来不及登记，重启后验证现有文件并补记，无需再次下载。
- 一个坏文件不会阻止同账号后面的其他文件；某个绑定失败不会中断其他账号、本地部署或视频生产。授权失效时显示断开，需重新连接。

## 4. 去重、发布和归档

- SHA-256与平台+账号键复用现有target_ledger，所有历史成功直接跳过投稿；未确认成功的结果继续使用既有失败1/失败2和新任务重试语义。每日真实上传次数仍由upload_quota计数并持久化，下载及历史成功去重不占上传额度。
- 同一个内容按本任务的平台顺序发布，完成该内容所需目标和一次重试后才处理下一内容。云盘下载不创建第二套平台上传线程。
- 2026.10.19.5起，本地和云盘来源媒体均进入其本地目录下`publiced`；同名同内容复用已有归档，同名不同内容另存`_重复`，冲突时继续编号。归档名不再由平台历史成功标记决定；旧目录不自动搬迁。[统一归档规则](UNIFIED_ARCHIVE_20261019.md)。
- 同一云盘系列绑定的所选账号是该系列的完成范围，未选择的平台不阻止归档。不同云盘系列的文件独立判断，不因另一系列没有该文件而永远无法归档。普通本地任务保留此前“本任务所选账号全部完成”的规则。
- 手工扫描清理可归档已完成文件；自动部署仍尊重所选账号的归档开关。目录重名、字幕重名均不覆盖旧文件。Google云端文件和日期文件夹始终保持原样。

## 5. 正式界面

- 账号矩阵池含账号列表及登录/DOM子框；每行有启用/关闭互斥开关。显示平台获取的名称，未登录的新账号显示待登录占位；不再提供可编辑备注。关闭不退出平台登录，正在执行的投稿按既有安全边界结束，后续文件停止该账号。
- 账号矩阵池始终显示，下方为“资源绑定 / 部署配置”两个横向标签页，默认资源绑定。资源绑定含独立“云盘绑定”和本地目录框；云盘类别使用通用名称，内容行显示具体服务名称与状态，目前实际接入为Google云盘。
- “启用云盘监听”、云盘名称/连接状态、连接/断开按钮在标题下同一行。断开时仅连接可用；已连接时仅断开可用；授权等待时两者均不可用。只有实际授权成功才显示已连接；保留更换连接。
- 部署配置含媒体类型、部署参数、平台参数三个子框；四个平台全部既有字段保留。平台参数固定标签列、输入左对齐；说明、频道和播放列表使用整行。
- 保存按钮和部署操作位于标签页外，切换后仍可见。配置表单不使用滚动条，通过分组、标签页和布局适配完整展示；较小窗口按内容最小尺寸展开，不能以隐藏字段代替适配。日志、多行文本及类似内容窗口保留滚动条；账号列表和媒体队列属于内容列表，仍可滚动。右侧原队列和控制台保留，状态条展示当前云盘下载/检查信息。全部可见复选框统一为媒体类型控件尺寸。
- 任务运行或预检期间，本地目录、云盘目录及媒体类型保持只读，停止后可更改，避免下载到新目录而活动任务仍扫描旧目录。连接/断开、账号启用/关闭、轮询间隔和每日上限仍可调整。

### 日期断点补扫（2026-10-17）

- 为每个“平台＋账号、本地目录＋云盘系列目录”在现有 `drive_ingest.sqlite3` 内增加 `scan_cursor` 表，不修改或清空已有文件版本与成功历史。
- 首次使用或旧配置尚无日期断点时，从北京时间当天开始记录，不猜测过去的扫描日期。换系列目录或本地目录形成独立断点；其他账号不继承该账号的进度。
- 例如最后检查 `2026-10-17`，停机至 `2026-10-20` 后，从17日再次检查，再按18、19、20日顺序补扫；补扫完成后只继续轮询20日，次日从20日衔接21日。重扫断点日可接收停机后追加的文件，已消费的同版本不会重新下载。
- 日期目录不存在则跳过；当天目录不存在仍等待下一轮。已越过的更早日期不会无限回溯，过去日期在断点之前新创建/补入的文件不会自动发现。
- 查询异常、取消或断开不越过未完成日期；大小/MD5未就绪、不可下载、下载或校验失败会保留最早未完成日期重试。坏文件不阻止当前轮后续日期处理；成功版本仍持久跳过。
- 全局总开关、账号开关、媒体过滤、下载校验、账号级历史去重、上传额度、成功 `publiced` 和重复 `_重复` 归档逻辑不变。目录提示与监听说明已同步为日期断点补扫。

### 同一本地目录的跨账号下载合并（2026-10-17）

- 现场发现抖音和快手共用同一系列与本地目录时，每个账号独立生成下载条目，第二个条目遇到同名文件后加后缀再次下载，三个云盘文件生成了六个下载记录及多份本地副本。
- 保留“平台＋账号”的版本条目、成功历史、额度与日期断点；仅对“同一本地目录＋同一 Google 云盘账号＋同一系列目录＋同一 Drive 文件 ID＋完全相同版本”复用已经验证完成的物理文件。本地目录、Google 云盘账号、系列目录中任一不同，均独立下载；若接收路径相同，使用安全后缀避免互相覆盖。不同云端副本仍按原约定下载后做内容去重。
- 共享文件先校验大小与 MD5，再为另一个账号登记其独立状态；不会改写共享文件的修改时间或添加待提交标记，避免干扰正在上传它的任务。
