# 微信视频号接入说明（2026.10.19.4）

微信视频号作为第五个发布平台接入现有书声部署流程。完整版第二页与独立部署版使用同一执行器、账号配置、下载及发布账本；完整版第三页仍保持锁定。

## 配置范围

微信视频号的“部署配置 → 平台参数”只提供两个字段：

| 字段 | 行为 |
| --- | --- |
| 短标题 | 按账号保存；填写时写入网页短标题并回读核对；留空保留网页默认。超过网页实际长度限制时停止，避免静默截断。 |
| 添加到合集 | 精确选择已有同名合集并回读；不存在、重名或控件结构不明时停止，不自动创建合集。留空保留网页默认。 |

视频描述固定留空，不从文件名、系列名称或通用正文配置生成描述。位置固定核对为“不显示位置”，如网页带入其他位置，通过位置控件选择“不显示位置”并回读。没有可辨认的设置入口时停止，避免带入错误位置。

链接、活动、定时发表、视频标注及其他选项沿用平台默认，不增加配置项，不自动声明原创或接受分成协议。本版本执行即时发表；如页面意外恢复了定时选项，停止并提示，不自行提交为定时作品。

云盘绑定、本地目录、媒体类型、每日上传上限、全部目标完成后归档等通用设置继续复用现有流程。

## 登录和发布边界

1. 在书声中选择“微信视频号”，添加账号，通过“登录 / 刷新账号”进入专用浏览器，扫码完成登录。
2. 从官方侧边栏底部本人账号区域读取昵称，不能使用作品作者、页面标题或扫码微信昵称代替视频号昵称。发布前与已绑定昵称实时核对。
3. 每个稳定账号 ID 使用独立浏览器目录。个人 DOM 诊断与内置结构规则分开，新设备仍需登录，不要求重复采集其他平台 DOM。
4. 上传过程复用共享工作流：实时账号校验 → 选择本次文件 → 短标题/空描述 → 等待传输和处理完成 → 平台默认封面 → 位置和合集 → 正式发表 → 等待回执。
5. 发布确认仅接受本次点击后产生的正式发表请求成功回执，或平台明确的“发表成功”通知。草稿、手机预览、列表跳转和描述中出现的成功文字均不构成成功。
6. 正式发表回执表示平台接收了本次投稿，平台后续审核仍由平台处理，与现有快手接收回执的语义一致，不声称作品已经公开或审核通过。
7. 成功结果按账号和文件内容摘要持久化，后续扫描、手工任务和重启均跳过；提交结果不明进入“中断待核验”，不自动重复上传；明确失败沿用两次尝试上限。

## 对既有功能的保护

- 新平台默认不勾选，不改变原有选中平台和账号绑定。
- 同云盘、同云路径、同本地目录的下载继续合并；不同绑定分别下载。视频号不会新增一条独立下载主管线。
- 归档仍由当前任务所选目标的完成情况统一决定，执行器不自行移动文件。
- 监控表新增“微信视频号”列，仅选择该平台时显示；日志新增同名标签。
- 非成功任务的截图、DOM 和任务日志保存到 `failure_diagnostics/微信视频号/日期/`，沿用现有诊断导出。成功任务不创建失败目录。
- 现有四个平台的上传执行器和生产模块保持原代码；调度器仅扩展执行器注册和原有安全分支覆盖范围。

## 本次核对与验收范围

已核对用户提供的发布页截图、官方公开前端中的本人账号区域、位置、合集控件，以及正式发表的请求路径和业务码处理。程序仅通过网页操作提交；回执监听只观察浏览器自身的请求，不直接调用或重放平台私有接口。

本地验证使用拦截全部网络的模拟页面及一次性账号目录，不读取真实登录资料、不真实发表。覆盖成功、明确拒绝、结果不明、错误账号、短标题限制、位置关闭、合集缺失、两端配置保存、失败资料和重启去重；还需在实际账号登录后完成首条作品的现场验收。

本地回归通过不等于已完成真实账号投稿或 X230 实机验证。首次现场测试时请只选择一条已确认可发布的视频，检查平台作品记录与书声结果是否一致。
