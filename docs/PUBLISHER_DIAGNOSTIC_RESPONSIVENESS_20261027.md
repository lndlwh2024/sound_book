# 2026.10.27.1：停止失效账号空转、视频号认证取证、后台导出

本次范围为2026-10-27确认的三项修改。独立发布包标签为`20261027-quiet-auth-diagnostics`，使用同一提交的共享发布源码、EXE和ZIP；版本及源码提交以包内manifest和实际运行自检核对。

## 任务内失效账号停止处理

任务中的暂停按平台及稳定账号ID隔离。确认需要登录或其他阻塞原因后，该账号在当前任务内不再自动检查、打开浏览器、开始后续文件或重试；队列保留首次失败原因及未完成目标。正常账号继续，云盘轮询下载仍独立运行。

已成功、已暂停、需人工核验、人工隔离或已达重试上限的项目，在进入上传批次前筛选，不再每5秒打印虚假的“批次开始”“文件开始”“本轮账号限制”。原有真实操作、首次失败、状态变化和新文件仍记录。定时本地扫描继续，但没有实质变化不重复刷日志。

失效期间新到文件也保留该目标的未完成状态，不能因停止重试就从全部所需目标中删除、提前归档或伪造成功。每日额度等待与认证失效分开，跨日或提高额度仍按原规则恢复。停止并重新启动部署才建立新的预检周期；不会在原任务内悄悄重新尝试已失效账号。

## 视频号认证记录

此前真实发布成功成立；本次增加取证，不把“核验可能过早通过”当作成功后掉登录的解释，也不宣称已查清平台真实认证失效的根因。

记录覆盖成功核验/发布、关闭前、重开与首次导航前、认证响应及失败页。重点为必要Cookie、视频号网页本地存储认证项的存在性、空值/不可读状态、数量及HMAC指纹，以及限定认证接口的HTTP状态和业务错误码。记录采集阶段、来源、当前页面与文件/任务关联，比较哪一阶段先发生变化。已恢复页面可能在观察器安装前执行过脚本时，应将这项限制明确记录。

不保存明文Cookie、令牌、账号标识值、请求参数、认证响应全文或完整带参数地址；指纹密钥保留为本机DPAPI保护文件，不导出。只观察视频号有关域和限定认证响应，不额外发起平台请求，不上传测试视频或回滚旧会话。无法读取单独标为不可用，不能当作认证项不存在。

这些记录输出到视频号窗口、日志和当前任务诊断包。失败不覆盖成功基线。材料变化也可能是正常刷新，不能仅凭变化自动认定失效原因；平台业务码和阶段顺序用于后续判断。

## 后台诊断导出

用户选择保存路径后，诊断文件收集、解析、去重、脱敏和压缩在后台执行；界面显示进度，防止重复并行导出。导出完成或失败后恢复按钮。退出时停止在途导出并纳入原有有界退出流程，不能在退出后弹窗或启动新工作。

仍按点击时的当前/最新任务与截止时间导出：一份任务日志、每组最后两次失败证据、相关认证摘要和最新独立云盘扫描；不把其他历史任务混进来，不截掉本任务必要日志来掩盖性能问题。取消保存不启动工作，导出失败可再次操作。

本次相关回归按用例去重为316项通过，0失败、0跳过；这是相关模块范围，不是整个工程的全量测试。功能集40项、最新视频号取证7项和退出专项4项包含在该数内，不能再次累计。
